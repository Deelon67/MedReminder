# Чек-лист приложения «Мои лекарства»

**Проект:** MedReminder. **Версия:** 1.0. **Платформа:** Android 11 и выше (API 30+).

**Назначение:** ведение домашней аптечки, планирование приёма лекарств, получение напоминаний, учёт выполнения схем и запись показателей здоровья.

Отметка **[x]** обозначает реализованную возможность текущей версии. В конце документа приведены отдельные пункты для проверки преподавателем на установленном APK.

## 1. Основные возможности

- [x] Четыре раздела нижнего меню: «Расписание», «Аптечка», «Дневник», «Настройки».
- [x] Русскоязычный интерфейс с единым оформлением карточек, полей и кнопок выбора.
- [x] Работа без регистрации и подключения к интернету.
- [x] Локальное сохранение препаратов, схем, отметок приёма, показателей и настроек после перезапуска приложения.
- [x] Проверка обязательных полей, подсказки при вводе и сообщения об ошибках сохранения.
- [x] Автоматическая заглавная буква при вводе названий препаратов, заметок и комментариев.

## 2. Создание схемы приёма

- [x] Создание схемы непосредственно из раздела «Расписание» без предварительного заполнения аптечки.
- [x] Автоматическое создание записи в аптечке при сохранении схемы для нового препарата.
- [x] Выбор существующего препарата из аптечки и создание нескольких схем для одного препарата.
- [x] Поиск подходящих препаратов при вводе названия, начиная с первой буквы.
- [x] Сопоставление названий без учёта регистра и лишних пробелов; отсутствие повторной карточки препарата в аптечке.
- [x] Ввод положительного целого количества на один приём и выбор единицы: таблетки, капсулы, капли, мл, мг, г, шт., впрыски.
- [x] Выбор курса: 7, 14 или 30 календарных дней.
- [x] Выбор даты начала курса: сегодня или будущая дата.
- [x] Выбор дней недели; для сохранения необходимо отметить хотя бы один день.
- [x] Несколько времён приёма в одной схеме.
- [x] Быстрый выбор времени завтрака, обеда и ужина из настроек.
- [x] Добавление произвольного времени через «Своё»: часы или цифровой ввод.
- [x] Необязательный комментарий к приёму.

## 3. Расписание и отметки приёма

- [x] Возврат к сегодняшней дате отдельной кнопкой.
- [x] Учёт даты начала, длительности курса и выбранных дней недели.
- [x] Отображение названия, количества на приём, времени и комментария.
- [x] Возможность отметить лекарство принятым за 30 минут до назначенного времени.
- [x] Действия для наступившего приёма: «Принято», «Отложить», «Пропустить».
- [x] Отсрочка из приложения на 15, 30 или 60 минут с показом нового времени напоминания.
- [x] Цветовые состояния: зелёный — принято; жёлтый — ожидание отметки или отсрочка; красный — пропущено либо прошло более часа без отметки; нейтральный — предстоящий приём.

- [x] Защита от повторного выполнения отметки одного приёма.
- [x] Отметки «Принято» и «Пропустить» окончательные: отмена не предусмотрена.
- [x] Удаление приёмов выбранной схемы только на выбранный день с подтверждением; препарат остаётся в аптечке, схема действует в другие дни.

## Условия и ограничения текущей версии

- Схемы и дозировки вводятся пользователем. Приложение не назначает лечение.
- Плашки показателей — справочная индикация. Диапазон температуры 36,6–36,8 °C задан в приложении и не является универсальной медицинской нормой.
- Автосписание требует указанного запаса и совместимых единиц. Капли и впрыски не переводятся в мл, а количество таблеток — в мг действующего вещества.
- Предупреждение о малом остатке формируется при списании после отметки приёма, а не просто при вводе малого запаса в карточке.
- Доставка уведомлений зависит от системных разрешений, настроек канала и ограничений Android. Без доступа к точным будильникам возможны задержки.
- Изменение распорядка влияет на быстрые кнопки новых схем, но не переносит время уже сохранённых приёмов.
- Дневник показывает текущий месяц. Его история рассчитывается по существующим схемам и отметкам; удаление препарата удаляет связанные данные.
- В этой версии нет облачной синхронизации, внешнего справочника лекарств, экспорта PDF/JSON, профилей близких и кнопки пробного уведомления.

Для проверки уведомлений рекомендуется Android 13 или новее. Нужно разрешить уведомления приложения. Для наглядности используйте учебные названия препаратов; выполнять реальные назначения для демонстрации не требуется.

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | В аптечке добавить «Учебный препарат»: таблетки, дозировка на упаковке 50 мг, запас 7 таблеток, будущий срок годности и заметка. | Препарат отображается в аптечке, сведения доступны в детальной карточке. |
| 2 | Через «Добавить схему приёма» указать 3 таблетки, курс 7 дней, начало сегодня, сегодняшний день недели и время через 2–3 минуты через «Своё». | Название уже заполнено; схема появляется в расписании, второй карточки препарата в аптечке нет. |
| 3 | Выйти из приложения и дождаться назначенного времени. | Появляется уведомление с названием, количеством и кнопками действий. |
| 4 | Нажать «Принято» в уведомлении и открыть приложение. | Приём отмечен зелёным, запас равен 4 таблеткам, появляется уведомление о пополнении. |
| 5 | Открыть «Дневник» → «Приём лекарств». | Видны отметка о принятии и рассчитанная статистика; при единственном наступившем и принятом приёме — 100%. |

| 7 | Создать ещё один учебный приём на ближайшую минуту и после наступления времени нажать «Пропустить». | Статус красный, запас не уменьшился, кнопки отмены отметки нет. |

| 9 | В дневнике добавить давление 120/80, пульс 80, глюкозу 5, вес 70 и температуру 36,7. Затем удалить одну запись с подтверждением. | Показатели, дата и время сохранены; плашки отображаются; удаляется только выбранная запись. |
| 10 | В настройках изменить время обеда, затем открыть новую схему. | Быстрая кнопка показывает новое время обеда. |
| 11 | Полностью закрыть приложение и открыть снова. | Препараты, схемы, отметки, остатки, показатели и распорядок сохранены. |
| 12 | Удалить учебный препарат из аптечки, подтвердив действие. | Исчезают препарат и его связанные схемы; напоминания отменяются. |

## Техническая реализация и автоматическая проверка

- [x] Kotlin, Jetpack Compose и Material 3.
- [x] Разделение на слои presentation, domain и data; ViewModel, репозитории и DAO.
- [x] Kotlin Coroutines и Flow/StateFlow для работы с данными и обновления интерфейса.
- [x] Локальная база Room: препараты и схемы, отметки приёма, показатели; миграции схемы.
- [x] Транзакционное сохранение отметки «Принято» вместе со списанием запаса.
- [x] SharedPreferences для распорядка дня и параметров повторов.
- [x] AlarmManager, BroadcastReceiver и PendingIntent для напоминаний; Koin для внедрения зависимостей.
- [x] Unit-тесты расписания, статистики, единиц, запасов, справочных диапазонов, проверок ввода и политики напоминаний.
- [x] Инструментальные тесты сохранения и миграций базы, удаления показателей, распорядка, отметок, уведомлений и учёта запаса.
