# Правила интерфейса MedReminder

- Названия препаратов, заметки и комментарии всегда начинаются с заглавной буквы. Применяйте это правило при вводе, вставке текста, сохранении и отображении старых записей.
- Используйте capitalizeFirstLetter из domain/model/CabinetNames.kt: меняйте только первую букву, сохраняя регистр остального текста.
- Названия препаратов сравнивайте без учёта регистра и лишних пробелов с помощью medicineNameKey.
- Для кликабельных кнопок выбора используйте общий SelectionChip из presentation/screens/SelectionChip.kt: стиль курса и дней приёма, одинаковые скругления, мягкое зелёное выделение, без галочек и дополнительных иконок. Применяйте его к новым и существующим группам выбора, чтобы они выглядели единообразно.
